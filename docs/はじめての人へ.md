# はじめての人へ

このリポジトリが何なのかを、予備知識なしで読めるように書いたものです。

---

## 一言でいうと

**Mac 1台の中だけで動く、自分専用のAI環境です。**

ChatGPT のようなサービスは、あなたの言葉を会社のサーバーに送って、あちらで考えて、答えを返しています。
この一式は違います。**考えるところが手元の Mac の中にあります。** 電源とこの Mac さえあれば、
インターネットが切れていても話せますし、書いた文章がどこかへ送られることもありません。

その上で、外から使えるようにしてあります。出先から LINE を送れば、家の Mac が考えて返事をします。

---

## 何ができるのか

### 話しかける

```
claw chat        ターミナルで話す
voice-ai         声で話しかけて、声で返してもらう
LINE / Discord   出先から話しかける
```

`voice-ai` は Option キーを押している間だけ聞きます。聞き取りも、考えるのも、話し返すのも、
全部この Mac の中で完結します。

### コードを書いてもらう

```
qwc              その場でコーディングを頼む（雑談もできる）
qwc-async        LINE から頼んで、結果を Discord で受け取る
```

`qwc` は「ファイルを読んで、直して、テストを走らせて、結果を報告する」まで自分でやります。
指示を出すのではなく、**手を動かしてもらう**道具です。

雑談も同じ画面でできます。言葉づかいから「これは作業の依頼か、ただの独り言か」を見分けるので、
「そういえば消費税って10%だよね」と言っただけでファイルが書き換わることはありません。

### 勝手にやっておいてもらう

| いつ | 何を |
| :--- | :--- |
| 毎朝 | 登録したテーマを調べて、要点をまとめる（`morning-brief`） |
| 毎日 | 今日の予定と天気を短くまとめる（`today-schedule` / `weather-line`） |
| 定期 | 決めたページを見に行き、変化があれば知らせる（`watch-pages`） |
| 定期 | SNS の下書きを作る（投稿はしない。承認したものだけ出る） |
| 毎日 3:30 | Downloads と Desktop を種類別に片付ける |
| 毎日 4:00 | この環境まるごとバックアップ |
| 毎日 12:00 | PC の状態を見て、気をつけた方がいいことだけ知らせる |

## 中身は4つ

```
        LINE / Discord / ターミナル / 声
                    │
              OpenClaw（受け口）
                    │
                    ├──→ qwc（コードを書く）
                    │
                    └──→ ollama（頭脳）
                              ↑
                        見張り（止まらないようにする）
```

| | 何をするもの |
| :--- | :--- |
| **`qwc/`** | コードを書く道具。ローカルのモデルで動く |
| **`openclaw/`** | LINE や Discord から話せるようにする設定 |
| **`guards/`** | 全体が止まっていないかを見張る層 |
| **`tools/`** | 日々の道具22本（声・SNS・調べもの・片付け） |

**頭脳（ollama）と受け口（OpenClaw）は、ここには入っていません。**
どちらも別のプロジェクトで、`brew install ollama` と `npm i -g openclaw` で入ります。
この一式は、その上に載せる部分です。

## いちばん大事な考え方

### この環境は、落ちずに「黙る」

普通、システムが壊れると止まります。止まれば気づけます。

ところがここで実際に起きたのは、**全部「動いているように見えるまま、仕事だけしなくなる」**壊れ方でした。

| 起きたこと | 外からどう見えたか |
| :--- | :--- |
| LINE のトンネルが死んだ | プロセスは生きていてログも出続け、**10時間気づかなかった** |
| 頭脳が答えなくなった | 状態表示は「正常・100% GPU」のまま、質問にだけ返事が来ない |
| 受け口が詰まった | 接続はできる。返事だけ来ない |

Mac には「プログラムが落ちたら再起動する」仕組み（launchd）が最初から入っています。
しかし上の3つは**どれもプログラムが落ちていない**ので、その仕組みは1つも助けてくれませんでした。

だからこの一式の見張りは、**「立っているか」ではなく「仕事ができるか」**を確かめます。

- 頭脳には、2分おきに**実際に一言しゃべらせる**
- LINE の入り口は、**LINE 自身に叩いてもらう**（自分で確かめると誤診するため）
- コードを書く側は、**書き捨てのフォルダで本当に1件やらせてみる**

### 見張りは、互いを見張る

```
   watchdog  ←─ 心拍を見る ─→  model-guard
      │  └─ 心拍を見る ─→  line-guard
      │  └─ 心拍を見る ─→  qwc-guard
      └──→ 受け口が黙っていないか
```

見張りにも見張りが要ります。ここでは4つが互いの「心拍」（走り切った跡）を見て、
止まっている相手を蹴り起こします。

**分けているのはプログラムであって、コードではありません。** 4つが別々に、別の時計で、
別の判断で動いているから、1つが黙っても他が気づけます。

最初は「共通の部品が壊れると全部が黙る」と考えて、同じコードを4つに書き写していました。
けれど実際に起きたのは逆で、書き写した当日に1つを編集ミスで壊しています。
いまは共通の道具を1つのファイルにまとめ、代わりにそれが壊れていないか毎回検査しています。

### 頼まれていないことは、しない

`qwc` は指示文で「問題を指摘されたら直せ」と教えられています。作業中は正しい態度ですが、
雑談では困ります。実際、この機能を入れる前は独り言だけでファイルが書き換わりました。

いまは言葉づかいから見分けます。**外したときの損得が左右で全然違う**ので、迷ったら
「雑談」側に倒します。

- 雑談を作業と間違える → 頼んでいないのにファイルが書き換わる（実害あり）
- 作業を雑談と間違える → 一度確認が出るだけ（`y` を押せば進む）

## 自動で動いているもの

| いつ | 何が |
| :--- | :--- |
| 2分おき | `model-guard` 頭脳が答えるか |
| 3分おき | `watchdog` 受け口の黙り・見張りたちの心拍 |
| 5分おき | `line-guard` LINE の入り口 |
| 毎朝 5:00 | `qwc-guard` コードを書く側が動くか |
| 常駐 | 受け口・LINE のトンネル / 中継 / URL同期 |

いまの状態は1つのコマンドで見られます。

```sh
claw status
```

```
● ollama    頭脳（gemma4:26b）
● gateway   本体（127.0.0.1:18789）
● LINE      トンネル / 受け口 / URL同期 / 外からの入り口
● 見張り    頭脳（ollama）  60秒前
● 見張り    本体と見張り  45秒前
● 見張り    LINEの入り口  0秒前
● 見張り    コードを書く側  48秒前
```

---

## できないこと

はっきり書いておきます。ここを曖昧にすると「見張っているつもり」が一番危ないためです。

- **見張りが全部同時に黙ったとき。** 4つが互いを見ているので確率は下がりますが、ゼロではありません
- **Mac ごと落ちたとき。** 中の誰にも気づけません。外の機械が要ります
- **`qwc-guard` は直せません。** `qwc` は常駐していないので蹴り起こす相手がおらず、知らせるだけです

## 言葉の意味

| 言葉 | 意味 |
| :--- | :--- |
| **ollama** | 手元でAIモデルを動かすソフト。この一式の「頭脳」。別プロジェクト |
| **OpenClaw** | LINE や Discord とつなぐソフト。この一式の「受け口」。別プロジェクト |
| **qwc** | この一式に入っているコーディング道具（Qwythos Code） |
| **見張り (guard)** | 止まっていないかを確かめて、直すか知らせるもの |
| **心拍 (pulse)** | 見張りが「今回ちゃんと走り切った」と残す跡。相手の死をこれで知る |
| **黙る** | 落ちてはいないのに仕事だけしなくなること。ここで一番多い壊れ方 |
| **launchd** | Mac に最初から入っている「決めた時間に動かす」仕組み |
| **gemma4:26b** | 使っているAIモデル。約17GBで、常にメモリに載せてある |

## 触ってみる

```sh
claw status      # 全体の状態
claw chat        # ターミナルで話す
qwc              # コーディング（雑談もできる）
watchdog --report        # 見張りの中身を見る
qwc-guard --report       # コードを書く側を確かめる（14秒）
```
